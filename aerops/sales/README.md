# AeroOps — Sales & Client Presentation Package

A complete, premium sales kit for presenting AeroOps to flight schools,
universities, flying clubs, corporate flight departments, partners, and
investors. Every visual is generated from the **newest AeroOps UI** — the
same screenshots the marketing site and the live application use, so there is
zero mismatch between what a prospect sees in the deck and what they see when
they log in.

## Honesty policy

This package is built to survive a six-figure buyer who will test every claim.
Anything marked shipped is demonstrable today in the live demo org; anything on
the roadmap (email/SMS, Stripe payments, live METAR, cloud document storage,
native mobile, predictive intelligence) is **labelled roadmap** wherever it
appears. In the comparison sheet, competitor capabilities we could not verify
from public information are marked **Unknown** rather than guessed.

## Regenerating (after any UI change)

Screenshots must always reflect the newest UI. From `aerops/`:

```bash
# 1. refresh product screenshots (app must be built + running on :3100)
node scripts/capture-marketing.mjs
node sales/capture-roles.mjs          # per-role dashboards → sales/assets/screens

# 2. rebuild every asset from the single source of truth (sales/deck-slides.mjs + *.md)
node sales/build-deck.mjs --pdf       # HTML decks + PDFs (master + 3 variants)
node sales/build-docs.mjs             # one-pagers + enablement PDFs
#    the .pptx is generated by scratchpad/pptx/build-pptx.mjs (pptxgenjs)
```

Diagrams (`assets/ecosystem.svg`, `workflow.svg`, `architecture.svg`) are
hand-authored in the AeroOps design language; their `.png` renders feed the
`.pptx`.
